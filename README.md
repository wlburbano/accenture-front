# Accenture - Task Manager (Ionic + Angular)

# Stack Tecnológico & Optimización

    Core: Ionic Framework + Angular.

    Rendimiento (Manejo de Memoria): Implementación de Angular Signals en reemplazo de RxJS/Zone.js.

    Persistencia: Almacenamiento local mediante `LocalStorage` con sincronización de estados.

    Feature Flags: Integración con Firebase Remote Config para el control de características en tiempo real.

    Nativo: Apache Cordova.

# Instalación

    1. Instalar las dependencias del proyecto:

        npm install

        ionic serve

# Compilar y preparar cordoba

    1. Ejecutar  el comando

        npm run android:prepare
